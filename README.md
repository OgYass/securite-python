# Template code Sécurité Python

## Description

Programme minimaliste de détection de packet suspect en python 

## Native

### Installation

Installer les dépendances :

```bash
cd template-securite-python
poetry lock
poetry install
```

### Utilisation

Lancer le projet :

```bash
poetry run tp1
poetry run tp2
poetry run tp3 

```
